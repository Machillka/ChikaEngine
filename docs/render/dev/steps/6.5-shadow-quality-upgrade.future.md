# Step 6.5 - Shadow Quality Upgrade

## Metadata

- Status: Planned
- Depends on: Renderer Step 5.6 shadow foundation and `docs/render/dev/steps/5.3-clustered-lighting.future.md` if many local-light shadows are required
- Estimate: 5-8 days

## Goal

把当前单方向光 PCF shadow map 升级为可扩展的阴影系统基础：Directional CSM、Shadow Atlas、稳定 bias/filter 设置和后续局部光阴影入口。

首版目标是稳定、可诊断、可回退，不追求一次实现所有阴影算法。

## Responsibility

- RenderWorld Light Proxy 保持光源数据入口，阴影系统根据 snapshot 构建 shadow views。
- RenderPipeline 管理 shadow map/atlas 资源，但具体 pass 由 Pass Module 添加。
- RenderGraph 表达每个 cascade/atlas tile 的 depth write 和 lighting read 依赖。
- Shader 通过 Reflection 读取 shadow data buffer、shadow atlas 和 sampler。

## Implementation

- 扩展 `ShadowSettings`：cascade count、split lambda、atlas size、per-light shadow enable、filter quality 和 stabilization 开关。
- Directional light 首版实现 2-4 cascades，使用 stable texel snapping 降低 camera movement shimmering。
- ShadowSystem 生成 `ShadowView`、cascade matrices、atlas rect 和 light-to-shadow mapping。
- RenderGraph 为 shadow atlas 注册 depth texture；每个 cascade/tile 写入明确 subresource 或 atlas rect。
- Lighting shader 使用 shadow data buffer 选择 cascade，并在 atlas 中采样对应区域。
- 保留现有单张 shadow map fallback：CSM 或 atlas 不可用时仍能运行 Step 5.6 基础路径。
- Debug view 显示 cascade 分区、atlas tile、shadow frustum 和 bias/filter 参数。

## Unit Tests

- Cascade split 对 near/far、lambda 和 camera resize 可预测。
- Stable snapping 在小幅相机移动下不会产生大幅矩阵跳变。
- Atlas allocation 对 0 lights、1 directional、多个 local lights 和超容量情况可诊断。
- Shader shadow binding 通过 Reflection 解析，不新增固定 binding 数字。
- 关闭 CSM 时 pass 数和资源回到单张 shadow map 基础路径。

## Delivery Checklist

- [ ] Directional CSM 在近景和远景都比单张 shadow map 更稳定。
- [ ] RenderGraph Debug Snapshot 显示 shadow atlas/cascade pass 依赖。
- [ ] Vulkan Validation 无 depth layout、array layer 或 sampler 错误。
- [ ] Debug overlay 能定位 cascade 边界和 light frustum。
- [ ] 有阴影质量前后截图和 GPU timing 记录。

## Boundaries

- 不在首版实现所有点光源 cubemap shadows。
- 不实现 contact shadows、VSM/EVSM、PCSS 或 ray traced shadows。
- 不把 shadow atlas allocation 写死在 Renderer 主类中。
- 不让 shadow view 反向修改 Gameplay light component。
- 不为了阴影质量牺牲现有 Forward/Deferred 共同数据契约。

## Next

- 根据验证结果选择：局部光阴影、VSM/EVSM、TAA/SSAO 或 Clustered Lighting 集成。
