# Step 6.4 - Reflection Probes and Screen Reflections

## Metadata

- Status: Planned
- Depends on: Step 6.3 and RenderGraph history/resource debug visibility
- Estimate: 5-7 days

## Goal

在环境 IBL baseline 之上增加局部反射能力。首版以 Reflection Probe 为主，SSR 作为可选增量，用统一 Reflection Data Contract 给 Forward/Deferred PBR 消费。

## Responsibility

- RenderWorld 或独立 Environment World 保存 reflection probe proxy，不让 Gameplay 持有 RHI handle。
- Renderer 选择影响当前 view/material 的 probe，并上传 probe data。
- Resource 层管理 probe cubemap、prefilter mip 和 fallback。
- Shader 基于 roughness、normal、view vector 和 probe influence 采样反射。

## Implementation

- 定义 `RenderReflectionProbeProxy`，包含 transform、influence radius/box、priority、cubemap handle 和 enabled flag。
- 首版支持全局环境 probe 和少量局部 probe；超过上限时使用 deterministic priority selection 并记录 diagnostics。
- Probe 数据上传为 Storage/Uniform Buffer，cubemap 使用 descriptor array 或选定 probe binding。
- PBR 反射先从最匹配 probe 采样，缺少局部 probe 时回退 Step 6.3 的 global prefiltered environment。
- 可选 SSR 只读取 current-frame depth/normal/HDR，输出 reflection contribution 或 mask；失败时回退 probe，不留下黑色洞。
- Debug overlay 显示 probe bounds、selected probe id、SSR hit/miss。

## Unit Tests

- Probe selection 对 distance、priority、layer mask 和 disabled state 可预测。
- 超过 probe 上限时不越界，diagnostics 记录 dropped count。
- Probe fallback 顺序固定：local probe -> global environment -> ambient fallback。
- SSR 禁用时不创建 SSR pass，结果仍使用 probe。
- SSR resource dependency 不在 Post Process 之后读取未定义 HDR/Depth。

## Delivery Checklist

- [ ] 金属材质能看到局部 probe 与全局环境的差异。
- [ ] Probe debug bounds 与 RenderWorld snapshot 一致。
- [ ] Forward/Deferred 使用相同 reflection data contract。
- [ ] SSR 开关不会改变没有 SSR 资源时的稳定性。
- [ ] 性能记录区分 probe sampling 成本和 SSR tracing 成本。

## Boundaries

- 不实现实时 cubemap capture 更新；首版使用导入或预烘焙 probe。
- 不实现 probe parallax correction 的复杂 box projection，除非首版数据证明必须。
- 不实现 ray tracing reflection。
- 不让 Reflection Probe 走普通 Mesh/Material RenderQueue。
- SSR 不作为唯一反射来源，必须有 probe fallback。
