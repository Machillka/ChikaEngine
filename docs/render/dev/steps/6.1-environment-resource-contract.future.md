# Step 6.1 - Environment Resource Contract

## Metadata

- Status: Implemented (2026-07-02)
- Depends on: Phase 5 foundation and the existing Reflection-driven binding path
- Estimate: 3-4 days

## Goal

建立 Skybox、IBL、反射和后续环境光照共用的环境资源契约。第一步只解决资源表达、导入、上传、View 和 Binding，不直接实现画面效果。

这里的 Environment Resource 指 Cubemap、Irradiance Map、Prefiltered Environment Map、BRDF LUT、Reflection Probe Texture 和默认 fallback 资源。

## Responsibility

- Asset 层描述环境贴图来源、颜色空间、mip 和 cubemap face 布局。
- Resource 层上传环境贴图并保存 stable GPU handle、Texture View 和 Sampler。
- RHI 层明确表达 cubemap/array texture view，不让 Vulkan 后端靠 `arrayLayers == 6` 猜语义。
- Render 层只消费后端无关的 Environment handles，不直接读取文件或 Vulkan 对象。

## Supported `.texture` Descriptor

```json
{
  "usage": "environment",
  "srgb": false,
  "generateMips": false,
  "mipLevels": 1,
  "cubeFaces": {
    "px": "right.png",
    "nx": "left.png",
    "py": "top.png",
    "ny": "bottom.png",
    "pz": "front.png",
    "nz": "back.png"
  },
  "fallback": "gray_irradiance"
}
```

`srgb` 由源数据决定，而不是由 `usage=environment` 固定决定：LDR PNG/JPEG Cubemap 应使用 `true`，让硬件先解码到线性空间再进入 HDR/tone mapping；仅线性数据或 HDR 导入结果使用 `false`。仓库默认 `default-skybox.texture` 的六张 PNG 因此使用 `srgb=true`。

### Current format boundary

- 已实现并验证：PNG/JPEG/TGA 等 LDR 8-bit 输入，上传为 `RGBA8_SRGB` 或 `RGBA8_UNorm`。
- Step 6.1A 已实现：Radiance `.hdr` 与 OpenEXR `.exr` 保留 linear float 动态范围，默认上传 `RGBA16_Float`，descriptor 可选择 `RGBA32_Float`。
- 六面 HDR/EXR descriptor 与单张 2:1 equirectangular HDR/EXR 均能形成浮点 TextureCube；后者的转换、项目示例配置与实际采样已由 Step 6.2A 完成。

Supported `usage` values:

- `color`
- `data`
- `environment`
- `environment_irradiance`
- `environment_prefiltered`
- `environment_brdf_lut`
- `reflection_probe`

Supported `fallback` values:

- `none`
- `gray_irradiance`
- `black_prefilter`
- `brdf_lut`

Import limits in 6.1:

- Cubemap faces must be exactly 6 and use the order `px, nx, py, ny, pz, nz`.
- Cubemap faces must have identical dimensions.
- `generateMips=true` 与 `mipLevels>1` 会被拒绝，直到存在真实 mip payload/generator；prefilter computation 仍属于 6.3/6.4。
- HDR/EXR float payload 与上传已由 Step 6.1A 实现；equirectangular projection 和运行时 Skybox 配置已由 Step 6.2A 实现并验收。

## Boundaries

- 不在本步骤绘制 Skybox。
- 不在本步骤计算 Irradiance/Prefilter。
- 不把 `ambientIntensity` 删除；它作为环境资源缺失时的低阶 fallback 保留。
- 不把 Vulkan `VkImageViewType` 暴露到 Render 或 Resource 公共接口。
