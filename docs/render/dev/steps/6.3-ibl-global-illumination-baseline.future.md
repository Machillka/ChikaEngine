# Step 6.3 - IBL and Global Illumination Baseline

## Metadata

- Status: Planned
- Depends on: Step 6.1A, Step 6.2A, Renderer Step 5.2 PBR foundation
- Estimate: 4-6 days

## Goal

把当前 `ambientIntensity` 标量升级为基于环境贴图的基础全局光照路径：Diffuse Irradiance、Specular Prefilter 和 BRDF LUT。

本步骤中的 Global Illumination 是静态/预计算环境间接光 baseline，不实现实时多次反弹、DDGI、SDFGI 或 Path Tracing。

## Responsibility

- Asset/Resource 提供 Irradiance Map、Prefiltered Environment Map 和 BRDF LUT。
- RenderPipeline 上传并绑定环境光照资源。
- Forward 和 Deferred PBR Shader 共享同一套 IBL 采样函数。
- RenderSettings 控制环境强度、IBL 开关和 fallback 行为。

## Implementation

- 将现有环境 fallback 拆成独立函数，明确 `ambientIntensity` 只用于 missing-resource fallback。
- PBR Shader 增加 diffuse irradiance 项：`irradiance * albedo * (1 - metallic)`。
- PBR Shader 增加 specular IBL 项：prefiltered cubemap mip 根据 roughness 选择，BRDF LUT 修正 Fresnel/geometry。
- Forward 和 Deferred 使用相同 shader include 或相同函数实现，避免两套光照公式漂移。
- 预计算路径首版可以选择离线生成资产或启动时 compute pass，但必须记录选择；不能每帧重复预计算。
- Environment 资源绑定通过 Reflection 解析到 stable handles，不允许在 draw path 中按字符串查找。
- 增加 debug view：显示 irradiance、prefilter mip、BRDF LUT 或 IBL contribution。
- 复用 Step 6.2A 已验证的 float Cubemap，不在本卡重复实现 HDR/EXR decoder 或 equirectangular projection。

## Unit Tests

- Roughness 从 0 到 1 时，prefilter mip 选择单调且不越界。
- Metallic 为 1 时 diffuse environment contribution 接近 0。
- 缺少 IBL 资源时结果回退到 `ambientIntensity`，且日志可诊断。
- Forward 与 Deferred 的 IBL binding 名称和 descriptor 类型一致。
- BRDF LUT 尺寸、格式和采样状态符合预期。

## Boundaries

- 不实现动态场景 bounce。
- 不实现 lightmap baker。
- 不实现 probe blending。
- 不把 SSR 或 Reflection Probe 放进本步骤。
- 不删除已有多光源直接光路径。
- 不用普通颜色 mip 代替 roughness-dependent specular prefilter。
