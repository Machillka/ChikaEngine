# Step 3.2 - Scene Query Suite

## Metadata

- Status: Planned
- Priority: Core
- Depends on: Step 3.1
- Estimate: 3-4 days

## Goal

建立统一、可过滤、可复用内存的 Scene Query API，覆盖游戏引擎最常用的 Raycast、Sweep 和 Overlap。

## Planned API families

- `RaycastClosest` / `RaycastAll`
- `SweepSphere/Box/CapsuleClosest` / `Sweep...All`
- `OverlapSphere/Box/Capsule`
- `PhysicsQueryFilter`
- `PhysicsQueryHit`

## Query filter

- layer mask
- `TriggerQueryMode`: UseGlobal / Ignore / Collide
- ignored GameObject IDs and Body/Collider Handles
- query-only / simulation-only participation
- optional backface policy for mesh shapes
- deterministic result sort: distance/fraction, then Collider Handle

## Planned modules

- new `PhysicsQueries.hpp`
- `IPhysicsBackend` query interface
- Jolt narrow/broad phase adapters
- `PhysicsScene` handle/owner translation
- `PhysicsSubsystem` and Scene convenience API
- debug query history hook
- `tests/integration/PhysicsQueryTests.cpp`

## Implementation checklist

- [ ] 所有 direction 输入校验 finite/non-zero 并在内部规范化，distance 保持世界单位。
- [ ] Hit 返回 GameObject、Body、Collider、distance/fraction、point、normal 和 material ID。
- [ ] closest 和 all-hit 共享 filter 语义；all-hit 结果稳定排序。
- [ ] query 只返回 registry 中仍有效的 engine handles，不泄漏 Jolt BodyID。
- [ ] 提供 caller-owned output buffer/vector overload，避免热路径每次分配。
- [ ] 支持 ignore self 和 ignore attached hierarchy 的 Framework convenience helper。
- [ ] Query 在 Simulate 运行时的线程规则明确；首版只允许 physics main-thread safe point。
- [ ] 无命中时完整清空/重置输出，避免沿用上一次 hit。

## Acceptance criteria

- Raycast closest/all 对距离、法线、排序和过滤结果正确。
- Sphere/Box/Capsule Sweep 能检测高速移动路径中的障碍。
- Overlap 能区分 Block、Overlap、Trigger 和 Ignore。
- ignore self、layer mask 和 trigger mode 可组合，结果无重复 Collider。
- 重复 10,000 次无命中查询不会持续增长临时内存。
- stale/destroyed Body 不出现在 query result。

## Verification

- `cmake --build build --target ChikaPhysicsQueryTests`
- `ctest --test-dir build --output-on-failure -R "Chika.PhysicsQuery"`
- closest/all、filter matrix、zero direction、inside-shape 和 allocation regression cases。

## Risks

- Jolt RayCast 的 direction 长度可编码距离；公共 API 必须统一为 normalized direction + maxDistance，避免距离重复缩放。
- Shape cast 的 initial overlap 语义需要文档和测试，不应由 backend 默认值偶然决定。

## Boundaries

- 不实现跨帧 async query 或 GPU query。
- Triangle Mesh face index/UV 只有在 Step 4.1 支持 mesh shape 后才开放。
